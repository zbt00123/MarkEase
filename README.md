# 📝 MarkEase

> ✨ **简单、轻量、易用的 Markdown 编辑器**

**MarkEase** 是一款专为 Windows 用户打造的 Markdown 编辑器，致力于让 Markdown 文档的编写与阅读变得更加简单、直观。无需复杂配置，打开文件即可开始创作！🚀

无论你是刚接触 Markdown 的新手，还是经常编写 README、技术文档和笔记的用户，MarkEase 都希望为你提供一个 **简洁、舒适、高效** 的编辑环境。✍️

---

## ✨ 核心功能

### 📝 简单直观，轻松编辑

无需记忆复杂的 Markdown 语法！通过简洁直观的工具栏，即可快速插入 **标题、加粗、斜体、引用、链接、图片、表格、任务列表、代码** 等常用格式，让 Markdown 编辑也能拥有接近普通文档软件的轻松体验。👌

### 👀 三种浏览模式，自由切换

根据不同的使用场景，MarkEase 提供三种模式：

📝 **编辑模式** —— 专注于 Markdown 内容创作，减少干扰。
👁️ **预览模式** —— 隐藏编辑内容，沉浸式阅读最终排版效果。
↔️ **分屏模式** —— 编辑与预览同时显示，一边编写，一边查看效果，并支持同步滚动。✨

无论是专注写作、阅读文档，还是调整排版，都可以快速切换到最适合的工作方式。

### 🐙 GitHub 风格 Markdown 渲染

提供接近 GitHub 的 Markdown 阅读体验，支持 **表格、任务列表、代码块、语法高亮、图片、引用** 等丰富内容，非常适合编写 GitHub README、项目文档和技术笔记。🚀

### 📑 长文档也能轻松浏览

根据 Markdown 标题自动生成文档目录，帮助你快速了解文章结构，并可快速跳转到对应章节。即使面对长篇文档，也能轻松定位和浏览内容。🎯

### 🌍 多国语言，无障碍使用

MarkEase 支持多种界面语言，让不同地区的用户都能获得更自然的使用体验：

🇨🇳 简体中文/繁体中文　🇺🇸 English　🇯🇵 日本語　🇰🇷 한국어

切换语言后即可即时应用，无需重新启动软件。✨

### 🎨 多种系统配色，舒适每一刻

支持多种界面配色方案，可根据不同环境和个人习惯自由选择：

☀️ **浅色模式** —— 清晰明亮，适合日常办公。
🌙 **深色模式** —— 减少夜间使用时的视觉压力。
🖥️ **跟随系统** —— 自动适应 Windows 系统的外观设置。

无论白天工作还是夜晚写作，都能拥有舒适、统一的视觉体验。🌈
